# Collect a small review sample without code

Open the [hosted Actor](https://apify.com/datascraperes/iherb-reviews-extractor?fpr=edudata),choose Input and paste a product/review URL or ID
into Products. Keep the initial2-review total and per-product caps for a first
test. Only reviews with photos is optional and returns links,not image files.

Review the Pricing tab and your run spending limit before Start. After the run,
open Dataset and Run summary. A finished process does not itself prove a full
collection: check complete,status,delivered count and any stop reason.

Export JSON,CSV or Excel from Dataset. Preserve productId and reviewId when
combining files. A separately started run is a new collection with new charges.
